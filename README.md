# QUIZ-GAME
A general knowlegde quiz game made using python code 

This program is a simple general knowledge quiz game.

It does the following:

- Shows a menu with options:
  1. Play quiz
  2. View instructions
  3. View score
  4. Exit
- If the user chooses to play, it asks six multiple-choice questions
- The user enters answers as A, B, C, or D
- Each correct answer adds 1 point to the score
- After all questions, it prints the final score
- It also shows the correct answers for any question the user got wrong
- The user can check the quiz instructions or the current score from the menu
- The program keeps running until the user chooses to exit

This is a beginner-friendly quiz program that tests knowledge and tracks the score during the session.
